## 第二部分：各 Skill 详细介绍

### 1. ai-collab-workspace（AI 协同工作区生成器）

- **作用**：在当前工作区生成一套完整的人机协同文件体系——目录骨架、AGENTS.md 流转图、工作台、任务包、交付物生命周期管理。
- **何时用**：想给某个项目建立"人 + AI 协作"的文件管理结构，或提到 AGENTS.md 管理结构时。
- **产出**：一整套工作区目录与规范文件。

### 2. canvas-writer（项目创新画布）

- **作用**：以单题逐轮的方式，把《产品经理的项目创新画布》的 25 个格子（产品基础信息 / 需求 / 方案 / 增长 / 竞争 / 财务 / 验证四问）逐格问完、逐格填上。全程生成实时 HTML 画布，浏览器中可看到画布被一格格填写、当前格子高亮。
- **边界**：只填画布，不写 BRD/PRD，不堆功能清单。
- **产出**：落在 `docs/canvas/<slug>/` 下的画布产物与台账。

### 3. industry-scene-researcher（行业场景研究员）

- **作用**：把模糊的行业目标收敛成 AI 助手可执行的落地方案，输出"五件套"——场景补位卡、AI 落地作战路径、人机混编任务表、3 天试点行动包、唯一下一步。
- **三条主线**：模糊需求快速收敛、材料驱动的证据增强判断、已有方案的落地推进。

### 4. knowledge-framework-builder（知识框架梳理）

- **作用**：把课程主题或教材资料（Markdown / DOCX / PDF / 图片 / URL）提炼成结构化知识脉络图，支持三档深度输出（框架 / 重点讲解 / 全节点讲解），含核心知识点提炼、概念依赖关系、防幻觉溯源标注。
- **导出格式**：Markdown / Markmap / Mermaid / OPML / PDF。

### 5. long-manuscript-expert（长文档专家）

- **作用**：把提纲、访谈、笔记、局部草稿或成稿推进为可编辑的长文档成果。
- **三类场景**：从材料启动新长文、从锚点续写或局部改稿、审阅收口已有成稿。
- **原则**：优先在当前回复交付可用结构或正文，不虚构研究与事实。

### 6. paper-quick-reader（论文速读）

- **作用**：AI 论文速读。三档深度（裸读 / 引导 / 精读）+ 页码级 Provenance 防幻觉 + 多篇对比，输出结构化笔记与核心观点摘要。
- **不做**：论文检索、文献管理、翻译、扫描件 OCR、论文写作/降重。

### 7. proposal-seven-steps-thinker（七步成诗思考搭子）

- **作用**：基于七步问题解决法，以咨询顾问和评审教练双重角色，逐步引导用户在写方案/提案/汇报前完成：问题界定 → 逻辑树分解 → 优先级排序 → 工作计划 → 关键分析 → 建议归纳 → 沟通故事板。
- **产出**：Markdown 演示大纲、结构化过程文档和交互记录。
